# quickbasket-web

React frontend for the QuickBasket e-commerce platform.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is optimized with route-level code splitting and vendor chunking.

## Tech

- React 19 + React Router 7
- Tailwind CSS
- Vite 7
- Axios (with JWT interceptors)
- Framer Motion
- Lucide React Icons
